While there were many more input methods, such as micro-entry or fly-in, the user found that most of these were commercial input methods, and that there might be thefts or subsequent placements.[Rime (China rhyme input method)](https://rime.im/), which is a fully indigenous open source input method, is highly customized.

### Sound Code and Code
The current input method can be divided roughly into two types of sound code and shape. The sound code is the pronunciation of the Chinese word, the most typical of which is the full spell input, which is the most used. This type of input can be summarized as "read-as-you-go " , which means that you can find it in the candidate page of the input method if you can read it. The shape code is the structure used to enter the Chinese word, the most typical of which is the five fast-known input. This type of input can be summarized as " write-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it-it

But there are also shortcomings in the sound code and the code input. The disadvantage of the sound code input is that the number of candidates is more numerous because of the same word in Chinese. The disadvantage of the code input is that it is costly to learn and requires the splitting of the pen.

So, the word " double-scrabble " is used here. Double-scrabble is also the range of sound-code input. But, unlike full-scrabble, a double-scrolling key corresponds to a voice mother or rhyme mother, and by combining this "sound mother/hing mother" the two-string key will be able to type a full-text spell. For example, full-scaffle input requires "shuangpin" and double-scaffles (pigs) simply type "ulpb" in. The number of hits on long-scope Han is significantly reduced. Of course, double-sculpture input still falls within the range of sound code, it is still impossible to avoid the multiple-sickness of the candidates, often requiring page-turning. So there are double-scrabbles that are used with the help code. But the study costs are too high to continue here (waiting for time to re-read), and interested friends can try to use the little crane sound to enter.
