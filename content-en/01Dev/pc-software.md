## Recommendations for software
The saying is: "It's a pre-emptive thing." The user recently bought a new computer and re-installed the software, and found a good set of software, but the user also found some principles and concerns that should be noted during the process. So here we can record some of the software used, as well as the principles or suggestions that are being used.

1. **Ocam Razor Principles**

The Ocam razor is simply "if not necessary, no additional entity," so please do not install this software if you do not need it. Some of the classic but unusable software in the computer will only take your memory, and it will be of no use. If you think you “may” use some of the software, download it and install it when it is used.

2. **Glorification principles**

For all software or terminal beauty, if it reduces efficiency or affects the work, then drop it in time. For example, the user has seen too many operations that add a good background to the programming interface, but has tried to find out that it is distracting and therefore not suitable for himself. Some of the glorification that improves the efficiency of the work, such as the end beauty of oh my posh, the author has tried to provide functions that are not available in the traditional terminal, so the author has chosen to keep them.

3. **All in one principle**

Many software (such as obsidian or zotero) have a large market of plugs, often involving a variety of aspects. Sometimes we want to put all the possible plugs on, and play with the various flower-hungry operations. And we need to think about whether the time and effort to install the plugs and use them could be higher than the original "clumbly" method or operation. If there is a question, we need to reconsider the need to learn about the software or plugins.

***A pre-reader.***: This post only gives some software and usage experience that the user considers useful until September 2025, but does not mean that it is the best or the right one. It is also not responsible for any changes you make on your computer. Before downloading the software, you should better back up the data to avoid unknown errors (although the user is not in trouble).
