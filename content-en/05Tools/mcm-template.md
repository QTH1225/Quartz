Before using this template, you should at least have some knowledge of LaTeX, not just to give up Word suddenly for the sake of joining MCM/ICM, which should include but is not limited to:

- Basic LaTeX Syntax
- Common LaTeX packages (e.g.,`amsmath`, `graphicx`, `hyperref`(Early)
- How to compile LaTeX documents (e.g., use`pdflatex`, `xelatex`, `lualatex`(Early)

If you do not have a LaTeX environment, it is recommended that compilation be done using online platforms such as Overleaf.
## Project structure

```
LaTeX-in-ICM-MCM/
├── template/                    # 主模板目录（推荐使用）
│   ├── main.tex              # 主文档入口
│   ├── part_1_pre.tex        # 问题分析部分（引言、假设、符号说明）

│   ├── img/                  # 图片资源文件夹

```

## Template Features

### MCM/ICM special functionality
- **Autocontrol Number Settings**: Through`\usepackage[1234567]{easymcm}`Auto set the team control number
- **Regular summary format**: Summary formatting and layout specifications that meet the official requirements of MCM/ICM
- **Professional font support**: Provide specialized font options for academic papers such as Times, Palatino, etc.
- **Smart Header Footer**: Auto-present team numbers, page numbers and chapter information

### Professional layout characteristics
- **Math formula support**: Complete AMS-LaTeX Mathematical Symbol Library, supporting complex formulae
- **Advanced Table System**：
  - Three-line sheet format (toprule/midrule/bottomrule)
  - Overleaf long table (longtable environment)
  - Multi-row multi-column table (multirow/multicollumn)
  - Self-adaptation to width (resizebox and extracolsep)
- **Algorithms Layout**: Use`algorithm2e`Pack to support fake code layout
- **Smart Cross-references**：`hyperref`and`cleveref`Joint use, achieve intelligent references

### Code Highlighting support
- **MATLAB code box**: Use`matlab-prettifier`Pack, support syntax highlights and line numbers
- **Python code box.**: Harmonize coloring program with MATLAB to support syntax highlights
- **Autoline Wrap**: Super-long code and comment automatically wraps up to avoid spilling problems
- **Unified Colour Scheme**：
  - Line number colour:`darkgray`
  - Keyword colour:`darkblue`(Bold)
  - Comment colour:`darkgreen`
  - String colour:`red!60`(Python special)

### Modular design
- **Subchapter management**_: Distinguishing papers into introductions, models, conclusions, appendix four separate documents
- **Custom Commands**: Through`new_command.tex`Centralize custom macro commands
- **Photo resource management**: Unified`img/`Folder manages all photo resources
- **Cache Management**: Autogenerated`_minted-main/`Directory cache code highlight results

## Quick start.

### 1. Environmental requirements
- **LaTeX distribution**: recommend TeX Live 2023+ or MiKTeX 22.0+
- **Compose Engine**: XeLaTeX (support to Chinese and Unicode) must be used
- **Additional Dependence**: need to install`minted`Package (for code highlighting)

### 2. Use Step
1. **Fetch Templates**: clone or download this warehouse to local
2. **Enter Template Directory**：`cd temple`
3. **Configure Basic Information**: Edit`main.tex`Documents:
   ```latex
   \usepackage[1234567]{easymcm}  % 将1234567替换为你的队伍控制号
   \problem{A}                   % 将A替换为你的题号（A/B/C/D/E/F）
   ```
4. **Preparation of content**: Preparation of four chapter papers:
   - `part_1_pre.tex`: problem analysis, assumptions, symbols
   - `part_2_model.tex`: Model-building, resolution-seeking process
   - `part_3_conclusion.tex`_: Analysis of results, summary of conclusions
   - `part_4_Appendix.tex`: Appendix contents of codes, data etc.
5. **Compile Document**：
   ```bash
   xelatex main.tex
   xelatex main.tex  # 编译两次确保交叉引用正确
   ```

### 3. Examples of common functions

**Insert Table**(Supporting long-forms across pages):
```latex
\begin{longtable}{@{\extracolsep{\fill}}ccccc@{}}
\caption{参数分析表}\\ \toprule[2pt]
\multicolumn{1}{m{2.5cm}}{\centering \textbf{参数}} & \multicolumn{1}{m{2cm}}{\centering \textbf{类型}} & \multicolumn{1}{m{3cm}}{\centering \textbf{范围}} & \multicolumn{1}{m{2.5cm}}{\centering \textbf{默认值}} & \multicolumn{1}{m{2cm}}{\centering \textbf{敏感度}} \\
\midrule
$\\alpha$ & Continuous & [0, 1] & 0.5 & High \\
\end{longtable}
```

**Insert Code**(Supporting MATLAB and Python):
```latex
% MATLAB代码
\begin{matlab}{MATLAB代码标题}{matlab:label}
% 你的MATLAB代码
A = [1, 2, 3; 4, 5, 6; 7, 8, 9];
result = sum(A, 2);
\end{matlab}

% Python代码
\begin{python}{Python代码标题}{python:label}
# 你的Python代码
def calculate_sum(matrix):
    return [sum(row) for row in matrix]
\end{python}
```

## Configuration Options

### Font Selection
Templates support multiple professional fonts, in`main.tex`_Other Organiser
- `\usepackage{mathptmx}` - Times font (medium rule)
- `\usepackage{palatino}` - Palatino font (officially recommended)

### Code Style Custom
Yes.`main.tex`, the definition of the code box is defined by:
- Line number style:`numberstyle`
- Key words:`keywordstyle`
- Comment Style:`commentstyle`
- String Styles:`stringstyle`

## Attention

### Compilation requirements
1. **XeLaTeX must be used**: does not support pdfLaTeX or LuaLaTeX
2. **Compile twice**: Ensure that cross-references and directories are correctly generated

### Document management
1. **Picture Path**: All pictures should be placed`img/`Synchronising folder
2. **Chapter Separation**: the content of each chapter is corresponding`.tex`Documentation
3. **Custom Commands**: New command should be added`new_command.tex`Medium definition

### Layout
1. **Table Width**: Use`resizebox`or`extracolsep`Control Table Width
2. **Code Length**: Long code recommended in appendix
3. **References**: manage with BibTeX in a format that meets MCM/ICM requirements

## • Problem resolution

### Common problems
1. **Compilation Error**: Check whether XeLaTeX is used and whether it is compiled twice
2. **Code display anomaly**: Check if there are any special characters in the code that need to be transliterated
3. **Table Layout Questions**: Reasonably set column width to avoid over-utilization`resizebox`
