这篇笔记按建筑平面图的绘制顺序，整理 AutoCAD 中的图层、轴线、墙体、门窗、标注和打印操作。

## 绘图前的设置

### 线型与线宽

先确定基本线宽 b，再为各类构件设置图层、线型和线宽。本笔记采用 b = 0.7 mm 的线宽组。

| 图线 | 线宽 | 用途示例 |
| --- | --- | --- |
| 粗实线 | b | 被剖切的建筑构造轮廓 |
| 中粗实线 | 0.7b | 次一级可见轮廓 |
| 中实线 | 0.5b | 一般可见轮廓 |
| 细实线 | 0.25b | 家具、尺寸线及辅助表达 |
| 粗、中、细点划线 | b、0.5b、0.25b | 按图样用途选用；定位轴线采用细点划线 |

常用线宽组如下，数值单位为 mm：

| 线宽比 | b = 1.4 | b = 1.0 | b = 0.7 | b = 0.5 |
| --- | --- | --- | --- | --- |
| b | 1.4 | 1.0 | 0.7 | 0.5 |
| 0.7b | 1.0 | 0.7 | 0.5 | 0.35 |
| 0.5b | 0.7 | 0.5 | 0.35 | 0.25 |
| 0.25b | 0.35 | 0.25 | 0.18 | 0.13 |

### 字体与字高

同一张图纸的字体控制在两种以内。图中说明和标注可采用长仿宋体，工程名称、图名和标题可另选宋体、楷体或黑体。

| 内容 | 本笔记采用的出图字高 |
| --- | --- |
| 字母、数字、尺寸标注 | 3.5 mm |
| 普通汉字说明、房间名称 | 5 mm |
| 轴号、门窗编号 | 3.5 mm |
| 图名 | 5 mm |

长仿宋矢量字体的打印线宽宜为 0.25～0.35 mm。字体设置使用 `STYLE`（`ST`）；本笔记使用的 SHX 字体组合为 `gbenor.shx` 和大字体 `gbcbig.shx`。

下文的字高、轴号直径和符号尺寸均按出图尺寸记录。采用模型空间放大图框的非注释性绘图方式时，文字和符号尺寸随图框放大倍数调整，尺寸标注的全局比例也同步设置。

## 定位轴线

1. 使用 `LAYER`（`LA`）创建轴线图层，设置细点划线和 0.25b 线宽；本线宽组对应 0.18 mm。
2. 使用 `XLINE`（`XL`）绘制水平、竖向构造线，再用 `OFFSET`（`O`）按开间和进深偏移。
3. 使用 `TRIM`（`TR`）修剪多余部分。交叉选择可从右向左框选。
4. 使用 `LTSCALE`（`LTS`）调整线型比例，使点划线的间隔清楚可辨。
5. 使用 `LENGTHEN`（`LEN`）的增量选项 `DE` 调整轴线端部长度，为轴号和尺寸标注留出位置。

## 墙体与门窗洞口

### 绘制墙体

1. 创建墙体图层，使用 `MLINE`（`ML`）绘制多线墙体，并将对正方式设为“无”。
2. 绘制完各段墙体后，双击多线进入多线编辑，使用“T 形打开”或“十字打开”处理交接处。
3. 需要按单根线段继续修整时，使用 `EXPLODE`（`X`）分解多线。
4. 使用 `EXTEND`（`EX`）延伸端部，使用 `JOIN`（`J`）合并相连线段。

### 留设洞口

根据门窗位置，用 `OFFSET` 定位洞口边线，再用 `TRIM` 修剪墙线。构造线 `XL` 或多段线 `PL` 可用于绘制定位辅助线。

相同洞口使用 `COPY`（`CO`）复制。按住 `Shift` 并单击右键，可从对象捕捉菜单选择中点等捕捉方式。

`MLINE`（`ML`）绘制多线，`PLINE`（`PL`）绘制多段线，二者用途不同。

## 柱、门窗与露台

### 柱子

创建柱子图层，使用 `RECTANG`（`REC`）按截面尺寸绘制矩形，再用 `HATCH`（`H`）填充。重复使用的柱子可通过 `BLOCK` 创建块，以柱子几何中心作为基点。

### 窗户

创建窗户图层，使用 `MLSTYLE` 设置窗框的多线样式。各图元的偏移量按其相对样式参考线的位置设置；以中心线为参考时，偏移量就是到中心线的距离。将多线比例设为 1 后，用 `MLINE` 绘制窗户。

### 门扇与开启线

门扇和开启线分别设置图层，以便使用不同线宽。

- 门扇：使用 `RECTANG` 按尺寸绘制。
- 开启线：采用细实线，使用 `ARC`（`A`）绘制。先指定起点，再按提示选择端点及圆心、角度等条件。

圆弧默认按逆时针方向绘制，绘制门的开启线前先确定起点、终点和开启方向。

### 露台

创建露台图层，使用 `PLINE`（`PL`）绘制轮廓。

## 楼梯、门窗编号与图框

### 楼梯

1. 创建楼梯图层，使用 `RECTANG` 绘制平台和梯段边界。
2. 绘制一条踏步线，使用 `COPY` 的阵列选项 `A`，按数量和间距复制；需要在两端之间均布时，使用“布满”（`Fit`）选项。
3. 删除起点处多余线段，用 `PLINE` 绘制上下行箭头，通过起点和端点宽度控制箭头形状。
4. “上”“下”等汉字采用长仿宋体，出图字高取 5 mm，矢量文字线宽取 0.25 mm。

### 门窗编号

门编号和窗编号分别使用图层，出图字高取 3.5 mm。竖向编号可使用 `ROTATE`（`RO`）旋转。

### 图框

采用模型空间出图时，可使用 `SCALE`（`SC`）按选定比例放大图框。布置图面时，同时预留尺寸线、轴号、图名和说明的位置。

## 尺寸标注与房间名称

### 标注样式

使用 `DIMSTYLE`（`D`），以 `ISO-25` 为基础新建标注样式。本笔记采用以下设置：

| 项目 | 设置 |
| --- | --- |
| 基线间距 | 7 |
| 尺寸界线超出尺寸线 | 2 |
| 尺寸界线起点偏移量 | 2 |
| 固定长度的尺寸界线 | 启用，长度 10 |
| 尺寸起止符号 | 建筑标记 |
| 标注所用文字样式的固定高度 | 0，由标注样式控制字高 |
| 标注文字高度 | 3.5 |
| 文字位置 | 始终保持在尺寸界线之间 |
| 全局比例 | 与模型空间图框放大倍数一致 |
| 小数分隔符 | 句点 |

表中的尺寸参数配合全局比例使用。设置完成后，将新样式置为当前。

### 绘制尺寸链

创建标注图层，按由内到外的顺序绘制尺寸：

1. 内侧尺寸：使用 `DIMLINEAR`（`DLI`）起标，再用 `DIMCONTINUE`（`DCO`）连续标注。
2. 中间尺寸：使用 `DIMBASELINE`（`DBA`）绘制基线标注，或用 `QDIM` 选择轴线快速标注。
3. 外侧总尺寸：使用 `DIMLINEAR` 标注。

空格键可重复上一条命令。连续标注前先选好基准尺寸，避免尺寸链错接。

### 轴号与房间名称

轴号单独设置图层，圆圈出图直径取 8～10 mm，圈内数字采用 3.5 mm 长仿宋体，矢量文字线宽取 0.25 mm。

房间名称单独设置图层，采用 5 mm 长仿宋体。

## 标高、图名与打印

### 标高

创建标高图层，线宽取 0.18 mm。标高符号斜边按 45° 绘制，出图高度约 3 mm；文字采用 3.5 mm 长仿宋体，文字对象线宽恢复为默认设置。

### 图名与比例

创建图名图层，通过 `STYLE` 新建宋体文字样式，取消“使用大字体”，出图字高取 5 mm。图名下划线可用 `PLINE` 设置宽度绘制，比例文字采用 3.5 mm 长仿宋体。

### 打印

使用 `Ctrl + P` 打开打印设置，依次选择打印机或 PDF 输出设备、纸张尺寸、打印范围、图形方向和打印比例。按放大图框的方式出图时，打印比例应与图框比例对应。

- 彩色打印可选用 `acad.ctb`。
- 黑白打印可选用 `monochrome.ctb`。

在预览中核对线宽、字高和图面范围。需要调整白边时，进入打印机“特性”，在“修改标准图纸尺寸（可打印区域）”中调整对应纸张的边距。

## 常用命令速查

| 用途 | 命令或常用别名 |
| --- | --- |
| 图层、文字样式、标注样式 | `LA`、`ST`、`D` |
| 构造线、偏移、线型比例 | `XL`、`O`、`LTS` |
| 修剪、延伸、合并、调整长度 | `TR`、`EX`、`J`、`LEN` |
| 多线、多线样式、多段线 | `ML`、`MLSTYLE`、`PL` |
| 矩形、圆弧、填充 | `REC`、`A`、`H` |
| 创建块、分解 | `BLOCK`、`X` |
| 复制、旋转、缩放 | `CO`、`RO`、`SC` |
| 线性、连续、基线、快速标注 | `DLI`、`DCO`、`DBA`、`QDIM` |
