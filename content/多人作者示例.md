# 多人作者示例文档

这是一个演示多人作者系统的示例文档。

## 功能说明

现在Quartz系统支持以下作者信息格式：

### 1. 单一作者（向后兼容）
```yaml
author: Tianhao Qin
authorLink: https://github.com/QTH1225
```

### 2. 多个作者
```yaml
author:
  - Tianhao Qin
  - 张三
  - 李四
authorLink:
  - https://github.com/QTH1225
  - https://github.com/zhangsan
  - https://github.com/lisi
```

### 3. 混合格式（部分作者有链接）
```yaml
author:
  - Tianhao Qin
  - 张三
  - 李四
authorLink:
  - https://github.com/QTH1225
  # 张三没有链接
  - https://github.com/lisi
```

## 使用建议

1. **协作文档**：对于多人协作的文档，使用数组格式列出所有贡献者
2. **个人文档**：个人笔记继续使用单一作者格式
3. **链接管理**：确保作者和链接的顺序对应
