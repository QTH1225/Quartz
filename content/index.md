# 关于我
我是秦天浩，目前是中国矿业大学力学与土木工程学院结构工程专业的2025级硕士研究生。

我目前跟随尹世平教授从事新型混凝土材料的研究。在此之前，我曾在乔亚宁教授的指导下聚焦于中国的“双碳”目标（碳达峰与碳中和）以及机器学习方法的应用。这些跨领域的探索让我收获颇丰。

我相信好的想法诞生于交流之中，所以非常期望与各位共同进步，并建立了这个网站，详情可以见[[AboutSite]]。如果你对我的研究或任何相关话题感兴趣，可以通过以下方式联系我：
- [Github](https://github.com/QTH1225) 
- [Email](mailto:tianhaoqin@qq.com)

# 研究兴趣与技能
目前我主要对以下内容感兴趣：
- 结构一体化新型储能材料

- 机器学习以及AI在工程中的应用
