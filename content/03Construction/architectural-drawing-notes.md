## 建筑图绘制
### 识图以及规范
#### 线的规定
实线：
粗（线宽 b，用于被剖切的建筑构造轮廓线）、中粗（线宽 0.75 b）、中（线宽 0.5 b）、细（线宽 0.25 b，用于家具线）；
点划线：粗（线宽b）、中（0.5 b）、细（0.25 b，定位轴线绘制）
这里使用第三组线宽，即 $d=0.7$

|  线宽比   | 线宽组  |      |      |      |
| :----: | :--: | :--: | :--: | :--: |
|   b    | 1.4  | 1.0  | 0.7  | 0.5  |
| 0.7 b  | 1.0  | 0.7  | 0.5  | 0.35 |
| 0.5 b  | 0.7  | 0.5  | 0.35 | 0.25 |
| 0.25 b | 0.35 | 0.25 | 0.18 | 0.13 |
#### 文字的规定
在同一图纸中，字体种类不宜超过两类：
长仿宋体（图中标注及说明汉字，标题栏及明细栏）、宋体、楷体、黑体（工程名称、大小标题、图样标题等）
文字大小取字母及数字 3.5 mm，汉字 5 mm
字体线宽宜为 0.25 mm-0.35 mm

### 轴线的绘制
采用构造线来绘制定位轴线，快捷键为 `xl`，需要先使用 `la` 快捷键创建定位轴线图层
该步需要更改线形以及线宽为 $0.25b$
可以使用快捷键 `o` 进行偏移
绘制好后使用 `tr` 快捷键进行修剪，选择 `c` 窗选并从右往左框选
由于点与线过密集，所以修改线形比例因子，快捷键 `lts`
使用 `tr` 进行多余轴线裁剪

### 墙体及门窗洞口的绘制
#### 墙体的绘制
采用多线命令进行绘制墙体，快捷键 `ml`，此时将对正类型改为无
绘制完对应墙体后需要进行打通，左键双击使用多线编辑，使用 *T 形打开*或*十字打开*选项
打通完成后使用快捷键 `x` 对墙体进行分解
根据墙体位置使用快捷键 `ex` 进行延伸，快捷键 `j` 进行合并
将轴线向外延伸，快捷键 `len + space + de + space`
#### 门窗洞口的绘制
主要使用偏移命令和裁剪命令进行修剪，也可使用构造线 `xl` 和多段线 `ml` 进行裁剪
门窗洞口相同时可以进行复制，`shift + 右键` 可以捕捉中点

### 柱子门窗和露台的绘制
#### 柱子的绘制
创建柱子图层，使用矩形命令进行绘制，快捷键 `rec`，选择直接指定尺寸
使用快捷键 `h` 进行填充
填充完成后使用快捷键 `bl` 进行创建块，拾取点选择柱子几何中心点
#### 门窗的绘制
- 创建窗户图层
WINDOWS使用多线样式进行绘制，快捷键 `mlstyle` 设置多线样式格式
更改多线样式中图元的偏移，偏移量设置为距中心的距离，设置好后将多线命令中比例改为 1
接下来使用多线命令绘制窗户

- 创建门图层
由于门与门线的线宽不同，所以门与门线是分开绘制的
使用 `rec` 矩形命令根据尺寸对门进行绘制

- 门线采用细实线进行绘制，先新建门线图层
以圆弧命令进行绘制，快捷键 `a` 指定起点后选择 `e` 指定端点
❗注意：圆弧命令的绘制方向是*逆时针*，所以应确定好起点与终点
#### 露台的绘制
创建露台图层
使用多段线命令 `pl` 进行绘制

### 图框楼梯以及门窗编号
当图框大小不满足要求时，使用快捷键 `sc` 进行放大
放大比例优先选择常用比例，不满足时使用可用比例，注意预留出标注以及轴号的距离

- 创建楼梯图层
仍使用 `rec` 进行绘制平台部分
选中平台线，快捷键 `co + space` 选择阵列 `A` 并选择布满，删去楼梯起点的多余线
多段线命令 `pl` 用来绘制箭头，改变起点与端点宽度
上下的文字需要创建文字样式，快捷键 `st + space` ，新建字体后选择 SHX 字体为长仿宋体 `gbenor.shx` 并使用大字体 `gbcbig.shx`，高度改为 5 并置为当前。另，注意文字的线宽为 0.25

- 门窗编号
切换窗户图层，注意字体大小为 3.5 mm，如有竖向文字可以使用快捷键 `ro` 进行旋转
❗注意：门和窗编号使用两个图层

### 标注与房间名称设置
#### 标注设置
首先应正确设置标注样式，快捷键 `D`，选择 ISO-25 新建，将基线间距改为 7，超出尺寸线改为 2，起点偏移量改为 2，勾选固定长度的尺寸界线，长度改为 10。将箭头改为建筑标记。
更改标注文字应先创建文字样式，高度改为 0，文字高度改为 3.5
调整选项中更改为文字始终保持在尺寸界线之间，更改全局比例为图框放大倍数（若不更改则会造成标注文字较小）
将主单位中的小数分隔符改为句点，置为当前后关闭。
- 创建标注图层
先绘制最内部尺寸，`dli` 启动线性标注，可以使用 `space` 重复上一条，命令快捷键 `dco` 进行连续标注
中尺寸使用快捷键 `dba` 启动基线标注或使用快速标注 `qdim` 并选择轴线进行标注，外部尺寸依然使用线性标注
若设定重合标注则使用 `dco` 快捷键进行设定
- 轴号绘制
先创建轴号图层，圆圈的直径宜 8-10mm，圆圈内数字采用 3.5 mm 长仿宋体，注意修改文字的线宽为 0.25
#### 房间名称设置

创建房间名称图层，更改文字样式为长仿宋体 5

### 标高、图名与打印
建立标高图层，标高线宽改为 0.18，标高符号的角度为 45 度，高度约为 3 mm，更改文字样式为 3.5 长仿宋体，线宽改为默认
建立图名图层，使用快捷键 `st` 创建宋体文字样式，取消勾选使用大字体，高度为 5 并置为当前，使用 `pl` 更改宽度作为底部线
图纸比例采用长仿宋体 3.5

图纸打印快捷键 `ctrl + p`，分别设置打印机名称、图纸尺寸、打印范围为窗口，图形方向。更改样式表若彩印采用 `acad.ctb`，黑白打印使用 `monochrome.ctb`.
若打印有白边的话可以点击特性-修改标准图纸尺寸并在下方找到对应图纸尺寸，点击修改后更改页边距即可
