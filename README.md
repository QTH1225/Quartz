## 关于项目

这个数字花园基于 [Quartz v4](https://quartz.jzhao.xyz/) 构建，这是一个强大的开源工具，帮助我将笔记和想法转化为可访问的网站。

## 主题和样式

- **主题**: 基于 Quartz v4 的现代简约风格
- **颜色方案**: 精心调制的浅色/深色模式
- **排版**: 优化的中文排版和阅读体验

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npx quartz build --serve

# 构建生产版本
npx quartz build
```
